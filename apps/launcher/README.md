# Desktop launcher

Tauri 2 + Vite + TypeScript shell for WinWing MSFS Vibration Bridge.

This package owns local preferences and Start/Stop against the shared bridge runtime via an embedded **bridge-host** sidecar. The webview never imports SimConnect or HID modules. The installed launcher does **not** require Node.js.

```bash
# from repo root — builds the sidecar then starts Tauri
npm run build:bridge-host
npm run dev:launcher

# or from this package (ensure-bridge-host runs automatically via beforeDevCommand)
npm ci
npm test
npm run typecheck
npm run tauri:dev
npm run tauri:build
```

## Sidecar

Tauri embeds `binaries/bridge-host-x86_64-pc-windows-msvc.exe` (generated by `npm run build:bridge-host` at the repo root). That binary is a `@yao-pkg/pkg` build of `lib/bridge/host.js` and includes the same `createBridge()` core as the CLI.
